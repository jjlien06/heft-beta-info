# Heft support

For beta feedback, open Heft in TestFlight and tap **Send Beta Feedback**. You can also [open a GitHub issue](https://github.com/jjlien06/heft-beta-info/issues/new). Public issues should not contain personal photos, private filenames or locations.

Useful beta checks:

- Grant limited Photos access and confirm only selected assets appear.
- Compare largest/smallest and newest/oldest sorting.
- Check that unavailable iCloud sizes show as unknown, not zero.
- Export test images/videos to a folder and inspect the copies.
- Convert test RAW files while keeping originals before testing optional deletion.
- Check cancellation, failures and external-drive reconnection.

A first scan can take time because it counts local bytes using public PhotoKit APIs. Results are cached. Cloud-only resources may have unknown sizes until available locally.
